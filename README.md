# Yene Birr 2.0 (የኔ ብር)

Ethiopian calendar personal finance tracker — offline-first Android APK.

**Version 2.0**
- New official app icon (green + yellow flower)
- 4 themes: Meskel Gold, Coffee, Indigo, **Sky Blue**
- Edit any transaction (tap row)
- Edit any account (tap card)
- Clear sample data properly (removes demo txs + resets demo account balances)
- Full reset still available

## Build APK (GitHub Actions)

1. Push this repo to GitHub
2. Actions → **Build Android APK** → Run workflow
3. Download artifact **yenebirr-debug-apk**

## Local

```bash
npm install
npm run dev
npm run build
```

Package ID: `com.melaku.yenebirr`  
App name: **Yene Birr**
